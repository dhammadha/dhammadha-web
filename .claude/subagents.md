# Subagents Configuration

ระบบนี้ประกอบด้วย 4 Agents หลักที่ทำงานร่วมกันเพื่อประสิทธิภาพสูงสุดและประหยัด Token:

1. **Main Agent** (Opus/Fable): ทำหน้าที่รับโจทย์จากผู้ใช้, คุยรายละเอียดข้อกำหนดให้ชัดเจน (Grill-with-doc), วางแผนงานแบบ DAG (Directed Acyclic Graph) และตัดสินใจเรียกใช้งาน Subagents
2. **Researcher** (Sonnet): ทำหน้าที่ค้นหาข้อมูลจากภายนอก, Lookup ข้อมูลในโปรเจกต์ และรวบรวมรายละเอียดที่จำเป็นเกี่ยวกับงานเท่านั้น
3. **Builder** (Sonnet): ทำหน้าที่เขียนโค้ด, แก้ไขไฟล์พร้อม ๆ กัน (Parallel) และ Implement งานตาม Plan ที่ Main ส่งมา
4. **Verifier** (Inherit จาก Main/Opus): ทำหน้าที่เป็นมุมมองคนนอก (Third-party) ตรวจสอบและ Review ผลลัพธ์โดยดูจากแค่ โจทย์ และ ผลลัพธ์ เท่านั้น เพื่อตัด Bias ห้ามแก้โค้ดเอง

*หมายเหตุ: ให้ Subagents ทั้งหมดสื่อสารกันและส่งต่อ Context ผ่านทางระบบอัตโนมัติของ Claude Code*
