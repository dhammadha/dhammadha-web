# typedee — logo study

ทุกไฟล์ในโฟลเดอร์นี้ถูก generate จาก [`build.py`](build.py) ไฟล์เดียว

```bash
python3 docs/design/logo/build.py
open docs/design/logo/contact-sheet.html
```

**ห้ามแก้ `.svg` ด้วยมือ** — แก้พารามิเตอร์ใน `build.py` แล้ว generate ใหม่ ไม่งั้น
ตัวเลขใน `metrics.json` กับรูปจะไม่ตรงกัน แล้วเถียงกันต่อไม่ได้

## โจทย์

ชื่อแบรนด์คือ **typedee** (พิมพ์เล็กเสมอ) / **ไทป์ดี** — โลโก้จึงต้องเป็นพิมพ์เล็ก
เจ้าของส่งต้นแบบมาสองรอบ:

- **รอบ 1** `tD` / `TD-TP` / `1D` — ตกทั้งหมด (ตัวใหญ่ขัดกฎแบรนด์, first-read ผิด)
- **รอบ 2** `d` พิมพ์เล็ก — ทิศทางถูกแล้ว เหลือแก้เรื่องฝีมือ 3 จุด

โฟลเดอร์นี้คือการแก้ 3 จุดนั้นทีละจุด เพื่อพิสูจน์ว่าจุดไหนมีผลจริง

## สถานะการวัด ⚠️

## สิ่งที่แก้ (และหน่วยที่ใช้)

หน่วยกลาง: **bowl height = 1000 เสมอ** ทุกค่าเทียบกับนี้ → เทียบข้าม variant ได้ตรง ๆ

| # | ปัญหาของต้นแบบ | ต้นแบบ | ที่แก้เป็น |
|---|---|---|---|
| 1 | counter เล็กกว่าเส้นนอนที่ขนาบมัน | 0.78× | **1.39×** |
| 2 | ascender สั้น อ่านเป็น `a` | 16.5% | **24.8%** |
| 3 | รูปในไม่ล้อรูปนอก (counter เป็นสี่เหลี่ยมมุมมน) | รัศมี 72 | **โค้งเต็ม 205** |

| variant | แก้อะไร |
|---|---|
| `d1-counter`  | ข้อ 1+3 อย่างเดียว |
| `d2-ascender` | ข้อ 2 อย่างเดียว |
| `d3-both`     | ทั้งหมด ← **ตัวที่แนะนำ** |
| `d4-lighter`  | เหมือน d3 แต่เบาลง 15% |
| `d5-micro`    | ปรับ optical size สำหรับ 16px ← **ใช้เป็น favicon** |

## ผลการทดสอบ 16px

`contact-sheet.html` เรนเดอร์ทุกแบบลง canvas 16×16 จริงแล้วขยายกลับมาแบบไม่เกลี่ยสี
(SVG ที่ย่อในเบราว์เซอร์ยังลบรอยหยักให้ดูดีกว่าความจริง — เชื่อไม่ได้)

| variant | 16px อ่านได้ว่า | ผล |
|---|---|---|
| `ref-round2` | ก้อนทึบมีร่อง → `a` | ✗ |
| `d1-counter` | มีรูชัด แต่ยังเป็น `a` | ✗ |
| `d2-ascender` | เป็น `d` แต่รูเกือบตัน | ✗ |
| `d3-both` | **`d` ชัด รูเปิด** | ✓ |
| `d4-lighter` | `d` ชัด รูเปิดกว่า d3 | ✓ |
| `d5-micro` | `d` ชัดที่สุดที่ 16px | ✓ |
| `t1-dee`, `t2-dee-light` | ก้อนโค้ง ไม่ใช่ `ด` | ✗ (ดูด้านล่าง) |

### สิ่งที่การทดสอบบอก และค้านสิ่งที่ประเมินไว้ตอนแรก

ตอนวิจารณ์ครั้งแรกผมบอกว่า **counter คือปัญหาร้ายแรงที่สุด** — การทดสอบแรสเตอร์บอกว่า
ไม่ใช่แบบนั้นทั้งหมด สองข้อนี้ทำงานคนละหน้าที่:

- **counter** ตัดสินว่า *"มันเป็นตัวอักษรหรือเป็นก้อนสี"* → d1 ผ่านข้อนี้ แต่ยังอ่านเป็น `a`
- **ascender** ตัดสินว่า *"มันเป็นตัวอะไร"* → d2 อ่านเป็น `d` ได้ทั้งที่รูเกือบตัน

ถ้าจะแก้แค่จุดเดียว **ต้องแก้ ascender** เพราะมันคือตัวที่ทำให้อ่านออกว่าเป็น `d`
แต่ที่ 16px ต้องมีทั้งคู่ถึงจะผ่าน — `d3-both` เป็นตัวเดียวที่ผ่านทั้งสองด่าน

## ด ไทย — ทำแล้ว แต่ยังไม่ผ่าน

โครงสร้างถอดมาจาก outline ตัว ด ของ Noto Sans Thai / Thai Looped จริง
(`public/fonts/pdf/`) ด้วย fontTools — ใช้อ้างอิงโครงเท่านั้น ไม่ได้เอา outline มาใช้

**สิ่งที่เจอตอนถอดโครง และเป็นเรื่องที่ดีสำหรับแบรนด์นี้:** `d` กับ `ด` เป็นญาติกันจริง —
ทั้งคู่คือ *bowl ด้านซ้าย + เส้นตั้งด้านขวา* ต่างกันแค่ว่าเอา "ส่วนเกิน" ไปไว้ไหน

- `d` → เอาขึ้นบน เป็น ascender, counter ปิด
- `ด` → เอาลงล่าง เป็นขาที่สะบัดขวา, counter เปิดด้านล่าง, เส้นตั้งหยุดที่ baseline

**แต่ผลจริงคือยังไม่ผ่าน:**

- ที่ 256px อ่านเป็น `ด` ได้ (ก้ำกึ่งกับ `ค`)
- ที่ **48px ลงมาช่องเปิดด้านล่างปิดตัวเอง** เหลือเป็นก้อนโค้ง อ่านไม่ออก
- สาเหตุเชิงโครงสร้าง: อักษรไทยมีรายละเอียดภายในมากกว่าละติน พอใช้น้ำหนักหนัก
  ระดับ DNA ของต้นแบบ (stem = 41.6% ของความสูง) มันตันเร็วกว่า `d` มาก
  → **น้ำหนักที่ `d` ใส่ได้ `ด` ใส่ไม่ได้** ซึ่งค้านสมมติฐาน "คู่พี่น้องน้ำหนักเดียวกัน"

**ข้อสังเกตเพิ่ม:** monogram เป็นธรรมเนียมของฝั่งละติน คนอ่านไทยไม่ได้อ่านพยัญชนะตัวเดียว
เป็น "โลโก้แบรนด์" แบบที่คนอ่านละตินอ่าน `d` — ต่อให้วาดจนอ่านออก มันก็อาจไม่ทำงาน
ในหน้าที่ที่ตั้งใจ

**ข้อเสนอ:** ไม่ใช้ `ด` เป็นมาร์คหลักหรือ avatar ถ้าอยากได้เสียงไทยในแบรนด์
ให้ไปลงที่ **wordmark ไทย "ไทป์ดี"** แทน ซึ่งมีที่ให้หายใจพอ

## ข้อเสนอ

| ใช้ที่ไหน | ใช้ตัวไหน |
|---|---|
| มาร์คหลัก (ทุกที่ทั่วไป) | `d-latin/d3-both.svg` |
| favicon / avatar 16–32px | `d-latin/d5-micro.svg` |
| ถ้าอยากได้ลุคเบาและแพงขึ้น | `d-latin/d4-lighter.svg` แทน d3 |
| `ด` ไทย | ยังไม่ใช้ — ดูเหตุผลด้านบน |

การมีสองตัว (ตัวใหญ่ + ตัวสำหรับขนาดเล็ก) ไม่ใช่การประนีประนอม — เป็นสิ่งที่ foundry
ทำเป็นปกติ (optical size) และเป็นเรื่องที่ควรทำอยู่แล้วสำหรับแบรนด์ที่ขายตัวอักษร

## ยังไม่ได้ทำ

- wordmark `typedee` แบบวาดเอง — ใน contact sheet ยังเป็นตัวเรียงชั่วคราว ใช้ดูสัดส่วนเท่านั้น
- สีแบรนด์ — ยังยึด near-black `#0A0A0A` / off-white `#EFEFEF` ตามต้นแบบ (ค่าประมาณ)
- ยังไม่แตะโค้ดเว็บเลย (`src/lib/brand.ts`, Nav, favicon, metadata) — รอเคาะโลโก้ก่อน
